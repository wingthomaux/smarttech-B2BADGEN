## Verifikation

`npm run verify`: Lint, Quellenkandidatenprüfung, deterministischer Katalog-Build, Übersetzungs-/Pfadprüfung und Worker-HTML-Tests. Neue Tests prüfen fünf individuelle DE/EN-Profile, sämtliche neuen Detailseiten, Domain-Suchvarianten, Zuordnung der Kommunikationsleistungen und Nichtvalidierung der zukünftigen Veranstaltung. Browser-QA ist ohne unterstütztes Browser-Plugin in dieser Umgebung nicht verfügbar. Vor Speicherung wird der geprüfte Commit nach main integriert, synchronisiert und mit `npm run release:check` geprüft.
